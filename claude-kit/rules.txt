# 这里每一行，Claude 都无法违反 —— 不是「它答应不这么做」，是它执行不了。
#
# 格式：  正则  =>  拦下来时给它看的解释
# 位置：  ~/.claude/rules.txt              全局生效
#         <项目>/.claude/rules.txt         只对该项目生效，且优先
#
# ── 用法（整套工具里最重要的一条习惯）────────────────────────────────
# 它再犯一次同样的错，别再口头纠正 —— 口头纠正只活到本次会话结束，
# 下次开新会话它就忘干净了。花 20 秒往这里加一行，这个错永久消失。
#
# 下面是示例。按你自己的情况改，用不上的删掉 —— 留着不适用的规则，
# 只会让它在正常干活时被莫名其妙地挡住。
# ─────────────────────────────────────────────────────────────────────

^npm[[:space:]]              =>  这个项目用 pnpm，不用 npm。把命令换成 pnpm 再执行。
--no-verify                  =>  不许跳过 pre-commit 钩子。钩子失败就去修，别绕过。
git[[:space:]]+push.*--force =>  不许强推。要覆盖远端就停下来问我。
^git[[:space:]]+checkout[[:space:]]+(main|master)$ =>  不要切回主干，当前工作应该留在特性分支上。
DROP[[:space:]]+TABLE|TRUNCATE[[:space:]] =>  绝不允许对数据库做破坏性操作，先跟我确认。
