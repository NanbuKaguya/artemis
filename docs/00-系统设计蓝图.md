# Artemis 系统设计蓝图

## 一、设计的出发点

大多数个人量化系统是这样搭的：找因子 → 回测 → 上实盘 → 亏钱 → 换因子。
这个循环的问题在于，它把最难的事（找 alpha）放在第一位，
把最有效的事（控亏损）放在最后甚至完全省略。

Artemis 反过来。**层级顺序就是设计声明**：

```
L7  复盘与纪律     管住你自己
L6  风控           止损、熔断、拥挤度
L5  执行           T+1 / 涨跌停 / 停牌 / 真实成本
L4  组合构建       分散度、行业约束、缓冲带
L3  选股 alpha     因子 ← 唯一需要"比别人聪明"的一层
L2  择时           市场状态 → 总仓位
L1  排雷           ST / 退市 / 流动性 / 财务地雷
L0  数据           point-in-time、防未来函数
```

## 二、每一层的职责与实测效果

### L0 数据层
统一契约（`data/schema.py`），所有数据源产出同一结构，策略代码与数据源解耦。
内置合成 A 股市场（`data/synthetic.py`）用于测试整条流水线 —— 它内置退市、
停牌、涨跌停、ST 转换，是回测引擎摩擦处理的试金石。

### L1 排雷层
**每条规则可度量**。`Guard().audit()` 报告每条规则剔除的样本后续表现：

| 规则 | edge | tail_saved vs 基准 | 判定 |
|---|---|---|---|
| ST | **+2.54** | 9.2% vs 5.7% | 均值尾部双赢，无条件保留 |
| 次新股 | **+1.67** | 5.9% vs 5.7% | 保留 |
| 停牌 | +0.28 | 6.3% vs 5.7% | 机械必需 |
| 微市值 | -0.89 | 6.2% vs 5.4% | 牺牲收益换尾部（保险费） |
| 低流动性 | -1.04 | 6.3% vs 5.5% | 同上 |
| 追涨停 | -1.06 | **8.6%** vs 5.7% | 尾部保护最强 |

设计要点：**排雷规则不是越多越好**。审计工具的价值是让每条规则的代价明码标价。

### L2 择时层
多信号投票（趋势/波动/宽度/回撤）→ 目标总仓位，带迟滞以抑制抖动。

**12 条平行历史实测**：回撤 **12/12 全部改善**（中位 -39% → -27%），
收益中位数变化 -0.2pp，平均仓位 62%。
即：用 62% 的仓位拿到几乎相同的收益，回撤少三分之一。

代价：牛市会跑输满仓。这是保险费，不是缺陷。

### L3 选股层
因子必须写清**经济逻辑**才允许注册（`@factor(name, why=...)`）。
说不清"谁在犯错、为什么这个错误能持续"的因子，大概率是在拟合噪音。

预处理管线：MAD 去极值 → 行业+市值中性化 → 截面标准化。
不做中性化的后果：你以为找到了 alpha，其实只是买了一堆小盘股。

### L4 组合层
等权 + 硬约束（单票 ≤10%、单行业 ≤30%），不用均值方差优化 ——
MVO 对协方差估计误差极度敏感，散户的数据质量撑不起它。

**缓冲带**（`hold_buffer=1.6`）：已持仓股票只要排名还在前 n×1.6 名内就继续持有。
6 条路径实测：换手 **6/6 下降**（中位 7.5x → 6.0x），成本 6/6 下降，
夏普改善 3/6（中性）。保留它的理由是可靠降成本，不是提高收益。

### L5 执行层（回测引擎）
强制处理的摩擦，每条对应一类真实亏损：

| 摩擦 | 对应的真实亏损 |
|---|---|
| T+1 | 你没有你以为的那么灵活 |
| 涨停不可买 | 一字板排队也买不到 |
| 跌停不可卖 | 最需要跑的时候跑不掉 |
| 停牌 | 净值是假的，复牌可能跳空 |
| 退市强制清算（折价 45%） | 幸存者偏差的解药 |
| 最小交易单位 | 小资金的实际约束 |
| 完整成本 26bp/次 | 换手 5x → 每年白亏 1.3% |

`tests/test_frictions.py` 的 14 项回归测试会拦住任何让回测变好看的"简化"。

### L6 风控层
单票止损 12% / 移动止盈 18% / 最长持有 60 日；
组合回撤 8% 预警、12% 降仓半、18% 熔断清仓 + 冷却 20 天。
写死在代码里，因为人在亏钱时不可信。

### L7 复盘与纪律层
- **事前承诺**：下单前必须写清买入理由和失效条件，标记 `system` 还是 `discretionary`
- **收益归因**：把收益拆成 beta / 择时 / 选股 / 成本四块
- **纪律评分**：低于 80 分说明执行是你的主要漏洞，不是策略

实测样例输出：

```
市场 beta   +29.42%   ← 钱全是 beta 给的
择时贡献    -11.14%
选股贡献     -3.16%
成本拖累     -3.73%
合计        +13.58%
```

年化 13.58% 看起来不错，归因说明它跟你的选股能力没关系。
**不做归因，你不知道钱是怎么来的，也就不知道它什么时候会停。**

## 三、AI 在系统里的位置

这是最容易做错的一层。

**LLM 不该做**：预测涨跌、直接出买卖信号、决定仓位、自动下单。
语言模型没有价格数据的先验，让它"看图说话"预测行情，
得到的是流畅的胡说八道 —— 而且因为流畅，你会信。

**LLM 该做**（`artemis/copilot/agent.py`）：
1. **因子假设生成** — AI 提假设，回测做裁决
2. **公告排雷** — 纯 NLP 任务，也是散户最难覆盖的信息盲区
3. **魔鬼代言人** — 对每个买入决策做反方辩护。人最缺的是主动找反面证据的意愿
4. **复盘归因解释** — 把数字翻译成"这周你为什么亏"
5. **研究流水线自动化** — 它最强的部分

一句话：**让 AI 做研究员和风控质检员，不要让它做交易员。**

## 四、这个系统不能给你什么

- 不能保证赚钱。内置因子只是示例，真实市场表现要你自己验证
- 不能替你承受回撤。熔断能限制损失，不能消除损失
- 不能替代纪律。纪律评分只是让你看见问题，改不改在你

## 五、最该记住的三个数字

- **26 bp** — A 股单次完整买卖的成本。年换手 5x = 每年白亏 1.3%
- **2.80pp** — 纯随机噪音在这套风控下也能跑赢基准的幅度。
  不设随机对照组，你会把这部分记在自己因子头上
- **3/6** — 缓冲带改善夏普的路径比例。一条路径上的"改进"，
  多数是运气
