# Artemis Lite —— 不上全系统的两周方案

完整系统从零到实盘不少于一年，而大部分人走不完。
但系统里有两块**不需要 alpha、不需要 Level-2、不需要财务数据**就能用，
而且恰恰是"少亏钱"贡献最大的：

1. **排雷** —— 买之前先看这票踩没踩雷
2. **纪律** —— 记下事前承诺，定期对账

数据依赖被压到最低：AkShare 一个免费接口。

---

## 一个关键区分（它砍掉了一大半数据工程）

| | 数据需求 | 难度 |
|---|---|---|
| **实时排雷**：这票今天踩雷没有 | 当前快照 | 一次 API 调用 |
| **历史审计**：这条规则值多少钱 | 历史行情 + 历史 ST | 抽样几百只，约 15 分钟 |

用当前 ST 名单过滤三年前的回测是未来函数，但用它判断"这票今天是不是 ST"完全正确。
日常用的那部分，数据要求低到几乎为零。

---

## 安装与四条命令

```bash
pip install pandas numpy akshare
```

```bash
python -m artemis.lite check 600519 000001 300750   # 排雷检查
python -m artemis.lite watch                        # 检查 watchlist.txt 里的自选股
python -m artemis.lite log                          # 记一笔交易的事前承诺
python -m artemis.lite review                       # 纪律复盘
python -m artemis.lite audit 200 3                  # 抽样审计排雷规则（做一次即可）
```

### `check` 的输出长什么样

```
    代码    名称   结论                                          踩雷        提示
600519  贵州茅台 ✓ 通过                                            —          —
000001  平安银行 ❌ 排除              当日涨停（买不进）(涨幅 +9.98%（涨停 10%）)          —
600666 *ST瑞康 ❌ 排除  ST/退市风险；市值下限(18.0亿 < 30亿)；低价股(1.85元)          —
300999  某冷门股 ❌ 排除                    市值下限(总市值 25.0 亿（红线 30 亿）)    当日成交清淡
301888   某妖股 ⚠ 注意                                            —      换手过热
```

分级是刻意的：`❌ 排除` 一票否决，`⚠ 注意` 只提示。全都做成否决，清单会空。

**ST 状态藏在股票名称里**（`*ST`、`退`），所以不需要额外的数据源——
这是 Lite 能只用一个接口的关键。

## 两周怎么走

### 第 1 周：把排雷用起来

**Day 1**（30 分钟）
```bash
pip install akshare
python -m artemis.lite watch      # 自动创建 watchlist.txt
# 把你的自选股写进去
python -m artemis.lite watch
```

**Day 2–7**：每天开盘前跑一次 `watch`。规则很简单——

> **清单上标 ❌ 的，今天不碰。**

不需要相信这套规则的理论，只要执行一周，你会自己发现哪些"❌"是对的。

### 第 2 周：把纪律记起来

**每次下单前**跑 `log`，回答四个问题：

```
为什么买（可证伪的理由）:
什么情况证明我错了:
来源 (system/discretionary):
当前情绪 (calm/fomo/fear/revenge/bored):
```

写不出理由和失效条件的，`log` 会拒绝记录并告诉你原因。
情绪填 `fomo` 或 `revenge` 会直接建议你 24 小时后再决定。

**这不是形式主义。** 行为金融学里最稳的发现之一是：人会在事后重构自己的决策理由
（"我早就知道会跌"）。事前承诺是唯一的解药。

**周末**跑 `review`：

```
临时起意占比 32.0%  ← 超过 10%，执行纪律是你的主要漏洞
冲动交易占比  8.0%  ← 超过 5%
```

`source` 那个字段是整个 Lite 里最值钱的东西。几个月后它会告诉你：
**你的"盘感"到底值多少钱。** 多数人的答案是负数，但你得看见数字才会信。

## 做一次就够的事：规则审计

```bash
python -m artemis.lite audit 200 3     # 抽样 200 只 × 3 年，约 15 分钟
```

它在**你自己的数据**上量化每条排雷规则的价值：

| 列 | 含义 |
|---|---|
| `edge` | 保留样本 − 剔除样本的平均收益差 |
| `tail_saved` | 被剔除样本中未来跌超 20% 的比例 |
| `tail_base` | 保留样本中的同一比例 |

判读：

- **edge 为正** → 免费午餐，无条件保留
- **edge 为负但 tail_saved 明显高于 tail_base** → 保险费，值不值看你的风险偏好
- **edge 为负且 tail_saved 也不高** → 这条规则在帮倒忙，删掉

审计会**先跑数据体检**，明确告诉你哪些结论不可信。
比如 AkShare 拿不到历史 ST，所以 ST 规则那一行不会出现在审计表里——
你不会误信一个不成立的结论。

---

## Lite 拿不到什么（诚实清单）

| 缺什么 | 影响 | 想补的话 |
|---|---|---|
| 历史 ST 记录 | 审计里 ST 规则那条无法验证 | Tushare `namechange` |
| 已退市股票 | 审计带幸存者偏差，体检会明确报出 | Tushare `stock_basic(list_status='D')` |
| 行业分类 | 无行业中性化、无行业集中度约束 | Tushare `stock_basic` 的 industry |
| 精确历史市值 | 用当前股本反推，增发/回购过的股票有偏差 | Tushare `daily_basic` |

一句话：**Lite 的日常功能是可靠的，审计功能是有条件的。**
体检报告会逐项告诉你条件满不满足。

---

## 什么时候该考虑上全系统

只有当这三条同时成立：

1. 你已经连续三个月每天跑 `watch`，并且真的没碰过清单外的票
2. `review` 里的临时起意占比稳定在 10% 以下
3. 你能说出审计表里每条规则的 edge 和 tail_saved 是多少

前两条是纪律，第三条是理解。三条都做到了，你才具备用完整系统的条件——
而且到那时候，你大概率已经不需要我给的因子了。

做不到也没关系。**只做 Lite 也是一个完整的答案**，而且是个不错的答案。
