# 反过拟合宪法

> 散户量化亏钱的头号原因不是"没找到好策略"，
> 而是"把一个过拟合的策略当成好策略上了实盘"。

## 第一条：锁箱数据只看一次

把历史切成三段：**训练 / 验证 / 锁箱**。

- 训练段：随便调参
- 验证段：检验想法，但每看一次，它就"脏"一点
- 锁箱段：在你决定上实盘之前，**一次都不许看**

看过一次，锁箱就变成了验证集，你就少了一道防线。这条最难守，也最值钱。

## 第二条：诚实记录你试过多少组参数

每试一组参数，你需要的夏普门槛就更高。这不是道德要求，是数学：

| 试验组数 | 纯运气能给的最高夏普 | 你要跑赢的线 |
|---|---|---|
| 2 | 0.26 | 低 |
| 20 | 0.95 | 中 |
| 200 | 1.38 | 高 |
| 2000 | 1.72 | 极高 |

*(σ_SR = 0.5, n_obs = 1000 时的收缩夏普测算)*

**实测演示**：150 组参数，真实夏普全都是 0.3。挑出最好的一组显示 **1.20**，
看起来是个能上实盘的策略。收缩夏普 DSR = **0.539**，正确识破这是运气。

用法：把每次调参的夏普都记进研究日志，然后
`antifit.trial_log_to_dsr(trial_sharpes, n_obs)`。

## 第三条：必须有随机对照组

**这一条能救你的命。**

排雷层、择时层、止损本身就会产生正超额。如果不跟随机组比，
你会把风控的功劳记在选股因子头上 —— 然后在因子失效时毫无察觉。

本项目的实测（合成市场，seed=7）：

| | 年化 | 相对基准超额 |
|---|---|---|
| 上帝因子（真实潜变量） | +7.33% | **+13.30%** |
| 纯随机噪音 | -3.17% | **+2.80%** |
| 满仓基准 | -5.97% | — |

随机噪音也能跑赢基准 2.8pp。**真实 alpha 只有 13.30 − 2.80 = 10.5pp。**
不做这个对照，你会以为自己的因子值 13.3pp。

## 第四条：参数高原，不是参数针尖

真实的 edge 对参数不敏感。持仓 20 只改成 25 只、周频改成双周频，
收益应该平滑变化。如果只有一组参数能赚钱，那组参数就是历史噪音的形状。

判据：参数网格里**正收益组合占比 ≥ 60%**。

## 第五条：区分"可靠"和"运气"

改进一个参数后，不要在一条历史上看结果。跑多条平行路径，问：
**改善的路径有几条？**

本项目实测（缓冲带 1.6 vs 无缓冲带，6 条平行历史）：

| 指标 | 改善路径数 | 结论 |
|---|---|---|
| 换手率 | **6/6** | 可靠 |
| 成本拖累 | **6/6** | 可靠 |
| 夏普 | 3/6 | 抛硬币 |

所以保留缓冲带的正确理由是"它可靠地降成本、对收益中性"，
而**不是**"它提高收益"。这个区别决定了它在实盘会不会让你失望。

## 上线闸门

`scripts/validate_strategy.py` 默认拒绝。全部通过才允许投真钱：

| 闸门 | 门槛 |
|---|---|
| 样本外夏普 | ≥ 0.8 |
| 样本外最大回撤 | ≤ 20% |
| 样本外/样本内衰减 | ≥ 50% |
| 随机对照 | 分位 ≥ 95% |
| 参数高原 | 正收益参数占比 ≥ 60% |
| PBO 过拟合概率 | ≤ 35% |
| 收缩夏普 DSR | > 0.95 |

## 四个经典陷阱（必查）

1. **未来函数**：T 日收盘算出的信号，最早只能 T+1 开盘执行。
   用 close-to-close 计算收益会系统性高估。
2. **幸存者偏差**：回测池必须包含后来退市的股票，且退市要按折价强制清算。
   本项目默认折价 45%。
3. **成本低估**：A 股单次完整买卖约 **26 bp**（佣金万2.5双边 + 印花税
   0.05% 卖出单边 + 过户费 0.001% 双边 + 滑点 8bp 单边）。
   年换手 5x → 每年白亏 1.3%。
4. **快照当历史**：见 `docs/01` 数据坑部分。
