# kb-lead —— 判断不是知识，直到它被记下、回溯、验证

记之前过四关，任何一关过不了就**不记**，并告诉用户为什么。

1. **层**：`institutional`（规则，年级衰减）或 `structural`（统计规律，季度衰减）。
   成交额、两融、估值分位、当前风格 = 状态层 → **不进库**，说"这个库不存这个"。
2. **tier 照实写**：是你**现在能指着的**来源，不是你相信它最初出自哪里。
   你转述的、你记得"好像是证监会说的" = L5。tier 是你声明的，库不核实 —— 所以由你守。
   L1 法规/公告原文 · L2 原始数据或自算 · L3 署名研报 · L4 财经媒体 · L5 自媒体/转述
3. **if_wrong 必须可证伪**：问自己"**什么样的观测能让我把它埋了？**"
   要点名：哪份数据/原文、什么口径、偏离多少。
   - ✗ "如果这条断言不成立就推翻它"（循环，形式合格但无用）
   - ✓ "按同口径（剔除区间内新上市、含 ST、前复权）自算与此偏离超过 1 个百分点"
4. **一行一事**：不带换行；复合断言拆开。已封闭区间的历史数字加 `--stale-after never`；
   "长期 / 通常 / 目前"这类用默认。

```bash
cd ashare-kb && ./kb lead "<一句话>" --layer <institutional|structural> --tier <1-5> \
    --src "<能指着的来源>" --if-wrong "<什么观测能埋了它>"
```

记完只报：`lead +1，verified 仍是 N`。**lead 不是产出**，别把它当成进展汇报。
